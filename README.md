Generative AI Research
Overview

This repository contains the research materials for the project "Using Generative AI Tools – Boon or Bane."

The repository includes research documents, datasets, analysis scripts, reports, and other supporting materials.

Repository Structure
Generative_AI_Research/
│
├── Literature_Review/
├── Quantitative_Analysis/
├── Qualitative_Analysis/
├── Drafts_and_Reports/
├── Additional_Materials/
└── README.md

Folder Description
Literature_Review/ – Journal articles, conference papers, books, and other literature.
Quantitative_Analysis/ – Survey data, analysis files, Python scripts, and spreadsheets.
Qualitative_Analysis/ – Interview transcripts, interview protocols, and qualitative analysis.
Drafts_and_Reports/ – Research proposals, conference papers, and final reports.
Additional_Materials/ – Supporting images, information sheets, and other media.
Collaboration

Please use meaningful or easy to understand commit messages when making changes. Create a separate branch when working on new changes and submit a pull request for review before merging changes into the main branch.

Version Control

GitHub is used to track changes and maintain different versions of the research materials. This helps the team collaborate and keep a clear history of the project.
